# Wellshoes · демонстрационный кабинет

Мобильная интерактивная демка: клиенты, CRM, сообщения и рассылки, товары и склад, задачи, финансы.

[Открыть демку](https://rustemirzin.github.io/wellshoes-demo/)

Все клиенты, операции, остатки и результаты отправок — демонстрационные. ИИ, мессенджеры, касса и маркировка симулируются. Изменения сохраняются только в браузере пользователя; вводите только вымышленные данные. Кнопка восстановления находится в разделе «Ещё».

Фотографии 16 моделей и логотип взяты с публичного сайта [Wellshoes](https://wellshoes.store/) для демонстрации. Размеры и другие параметры товаров в демке условные. Шрифт Manrope: SIL Open Font License, лицензия включена в HTML.

Приложение работает как один автономный файл index.html. Запись встречи, рабочие документы и данные реальных клиентов в репозиторий не включены.
